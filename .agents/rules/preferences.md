# User Preferences & Constraints

1. **No Browser Testing**: Never invoke the browser subagent or open browser testing tools. Perform verification through file inspection, local server checks, or terminal output.
2. **Zero Emojis in UI**: Never use emojis in the user interface, icons, badges, buttons, or text. Always use clean SVGs, typography, or standard semantic icons.
3. **No Looping Animations**: Avoid infinite or continuous looping animations (e.g., pulsing, radar auras, continuous bounces) across all UI elements to uphold accessibility standards (WCAG / reduced motion).
